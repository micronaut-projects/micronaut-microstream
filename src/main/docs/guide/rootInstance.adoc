WARNING: MicroStream cannot persist Python objects yet. The Java class the Python compiler generates for a Python class keeps a reference to the underlying GraalPy object, which MicroStream refuses to store (`PersistenceExceptionTypeNotPersistable`), and Micronaut cannot instantiate a `@dataclass` root through its no-arg constructor. The Python samples in this guide show the intended API (`RootProvider`, `StorageManager`, `@StoreParams`, `@StoreReturn`); until the Python compiler supports it, declare the root instance and the entities it references as Java classes (the generated class of a Python class has no `io.` prefix, for example `micronaut.microstream.docs.Data`).
